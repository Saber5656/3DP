# Claude & Cloud — A2 / A3・4部品版

完成時の高さは各48 mm。各キャラクターを **本体1個・雲1個・左右の目2個** で組み立てます。
背面を丸く整え、雲の底面に頭の突起を受ける凹部を設けた改善版です。雲は一体成形で、継ぎ目や別の連結ピンはありません。

## ファイルと色

| 部品 | A2 | A3 | 色 |
|---|---|---|---|
| 本体 | `stl/A2-body.stl` | `stl/A3-body.stl` | オレンジ |
| 雲 | `stl/A2-cloud.stl` | `stl/A3-cloud.stl` | 白 |
| 左目 | `stl/A2-eye-left.stl` | `stl/A3-eye-left.stl` | 黒 |
| 右目 | `stl/A2-eye-right.stl` | `stl/A3-eye-right.stl` | 黒 |

各ファイルを1個ずつ印刷します。`assembly/` の3MFは完成形の確認用で、そのまま印刷する配置ではありません。
`stl/` は底面をZ=0に揃えた印刷向きです。雲には底面からサポートが必要です。

## 組み立て

1. 雲の底面と凹部のサポートを除去します。
2. 同じ型番の本体と雲を合わせ、突起を凹部に入れます。凹部の設計上の隙間は片側0.25 mmです。
3. 左右の目を本体の位置に合わせて接着します。

48 mmでのメッシュとCAD上の嵌合を検証済みです。改訂版の実物の嵌合・サポート除去後の仕上がりは、印刷後に確認します。
以前印刷した本体の突起ともCAD上で干渉しない設計です。

## サイズ変更

STLを拡大・縮小する場合は、同じキャラクターの4部品すべてに同じ倍率を適用してください。
隙間も倍率に応じて変わるため、変更した大きさでの嵌合は再確認が必要です。
元CADの自動出力は48 mmを検証済みの基準としています。

## データの来歴

改善版v2の一体雲と本体・目を形状変更せずまとめています。元の7部品版と既存ZIPは保持しています。
`manifest.json` はコピー元とのSHA-256一致、STLの閉じた形状・体積・寸法、組立3MFの4部品・高さ48 mmを記録しています。
元データとの一致検証はリポジトリ内の `scripts/validate_release.py` で実施しました（配布ZIPには検査スクリプトを含めていません）。印刷の実行記録は隣の[白黒部品](../print-run-four-part-20260924/README.md)と[オレンジ本体](../print-run-orange-20260925/README.md)に保存しています。

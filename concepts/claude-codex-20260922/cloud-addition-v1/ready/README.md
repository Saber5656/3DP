# 今回の6種類: A1〜A4・B4・D3

全て高さ48mm、各1点。28部品、4色の別プレートを印刷後に接着する。

| 印刷データ | 部品数 | 材料 | スライサー見積り |
|---|---:|---|---:|
| [white.3mf](white.3mf) | 7 | PLA Basic White | 1時間39分03秒 / 36.71g |
| [orange.3mf](orange.3mf) | 6 | PLA Basic Orange | 2時間44分54秒 / 56.16g |
| [black.3mf](black.3mf) | 14 | PLA Basic Black | 28分02秒 / 9.00g |
| [translucent_blue.3mf](translucent_blue.3mf) | 1 | PLA Translucent Blue | 24分07秒 / 6.53g |

**合計5時間16分06秒・108.40g。** 実時間/実使用ではなくスライサーの値。支持・ブリム等を含む見積りで、開始排出、交換、支持除去、接着時間は実際と異なる。

X2D / 0.4mm / Textured PEI。0.16mm層、3周、15% gyroid、3mmブリム。白・橙のみ同材tree support。色はスロット番号に固定していない。白は別ジョブで補助Extに装着された記録があるため、今回の主ノズル用データの送信時に実際の給送経路を合わせる。現在の印刷を停止・変更・送信する操作はしていない。

- 白: A1〜A4の雲4、D3クッション1、B4記号2。
- 橙: 6種類のClaude本体。
- 黒: A1〜A4の目8、B4の目2と台座1、D3の目2とロゴ1。
- 青: B4のCodex本体。

D1/D2/D4はこの印刷データに含めない。旧モデル/旧5種類のプレート/旧ZIPは残してある。

STLと3MF再読込、部品SHA、全28部品の初層と層番号連続性、ベッド内の実押出経路、機種と材料設定を検証した。`*-layers.png` は実G-codeの代表層。元のモデル一覧・hashはselection.json、全層の集計はslice-reports.json。

実機送信、GUI再読込、現物の支持除去・接着・はめ合い確認は未実施。別の印刷が終わってプレートを空にした後、材質/ノズル/給送割当を確認して使用する。

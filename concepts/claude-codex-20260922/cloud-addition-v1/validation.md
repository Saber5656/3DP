# A1〜A4追加・訂正後6種の検証

2026-09-22。ユーザー訂正「A1〜4,B4,D3」を採用。既存5モデルと旧ZIPを保持し、A1〜A4を高さ48mmで追加した。実機と外部公開はNOT_RUN。

## 形状と出力

- A1〜A4、各4部品、追加16部品。mm座標のCAD、印刷用STL、組立3MF、表示用GLB(m/Y-up)、正面/側面/背面/斜視の実メッシュ画像。
- 各完成高さ48mm、4つの平らな足底を確認。均一密度のソリッド近似の重心投影が足底凸包を1mm内側へ縮めた範囲内。実造形の重心/転倒試験ではない。
- 全部品が閉じた単体、正の体積、STL再読込で接地Z=0。部品間交差は0.01mm³未満。雲は真上から下降する経路に組立用余裕を持つ。
- 黒い目は各2つ、A4だけ横長。目の最小寸法1.15mm超。雲の基本形と体/目の位置は元コンセプトを参照し、背面と受けは新規設計。
- 旧原本/成果物/ZIPの追加前118ファイルをhashで照合。スライス前後は一時ファイルも含む旧ツリー201ファイルを照合し、不変を確認。旧D1/D2/D4は今回のプレートに含めない。

## TDDと修正の履歴

1. 7形状テストを先に作り、cloud_models未作成のModuleNotFoundErrorでRED。CAD実装後、A3のbinary STLで閉形が崩れる問題を検出。
2. 雲は解析的な楕円体の距離場から作り、丸みを保持。float32のSTL書出しで頂点が一致しゼロ面積三角形が残るため、書出し前にfloat32へ丸めて溶接し、初期対応では非閉形の場合に退化面を除去する処理を追加（後述の追加修正で閉形時の退化面も対象化）。無差別な標準validateはA1の有効な細い三角形まで削るため採用せず、高さ1e-12の退化判定を使用。bounds差1e-5mm以内、体積比差1e-5以内、閉形/正体積/単体をassert。
3. 画像でA3の頭キーが少し露出するのを認め、雲の前髪を1房追加して隠した。顔の両目は保持。
4. 独立レビューでA3/A4の後ろの肩に約0.20〜0.26mmの薄膜が残ることを観測。既知位置の0.05mm立方体probeが0.000125mm³交差するREDを追加。頭/肩の受けを後面まで開放し、不要な薄膜を除去。前面外形、4つの閉体、48mm、組付け経路を再確認。
5. 背面修正後、8形状テストと16バッチ補助テスト、合計24件PASS、1.683秒。補助テストの合成fixtureを実CLI/実機の成功に流用せず、実28部品の4プレートでも別途スライス。

6. 独立した最終binary検査で、閉形なA3雲にも面積0の三角形が1面残ると判明。印刷姿勢/組立姿勢の計32STLを直接float32→float64で読み、全facet面積>0を要求する回帰テストを追加しREDを確認。閉形性だけに頼らず面積0のときだけ1e-5mm単位の頂点溶接→退化面除去を適用。1e-6mmでは座標丸めの境界によって組立姿勢で閉形を維持できず不採用。採用後のA3はbounds差0、体積相対差約5.5e-13、全25テストPASS（2.028秒）。全出力を再生成し、STLのSHA変更がA3_cloudだけであることを確認。白プレートのみ再スライス、残る3色は同じ入力hashの実結果を再利用。最終見積りは5時間16分06秒・108.40g。

修正前のメッシュ/画像/スライスはローカルslice-work/model-initial.zipとcorrected-initialに保持。配布用readyには最終修正版を置く。新しいコード以外の、旧5モデルのテストは結果を再利用し、不変の同一証拠を再レビューしていない。

## 実スライスと層確認

既存のBambu Studio2.8.2.61/X2D0.4/PEI/公式PLAプリセットと変更なしの補助を使用。訂正後A1〜A4+B4+D3の28部品は白7・橙6・黒14・青1。48mmや部品hashが一致しなければスライス前に拒否する。各色を1枚へ配置、接地面の自動変更なし、配置のZ回転は許容。白/橙は同材tree support。

機種と材料設定、公式開始/終了テンプレート、実G-codeの部品数・各部品の初層と層番号連続性・ベッド内XY押出経路を検査。各色の代表4層を実経路から描画して確認。これは全オーバーハングの支持/除去性を厳密に証明する検査ではない。雲の受けは後面へ開放し、支持に届く経路を設けた。

CLIはorganic supportの既定選択、公式終了テンプレートのT65279/T65535解釈警告を出した。対応コマンドが全出力の最終層後に存在し、公式テンプレートと一致することを確認。機器上の成功へ読み替えず、ログを保持する。最終見積り・hash・層ごとの集計はready内のJSONが正本。

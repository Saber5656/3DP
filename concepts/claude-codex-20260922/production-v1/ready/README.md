# 48mm版・X2Dの印刷待機データ

5種類各1点、23部品。色別に1枚ずつ印刷して接着する。各ファイルは独立した印刷ジョブ。

| 色 / データ | 対象 | 材料 | 見積り |
|---|---|---|---:|
| [gray.3mf](gray.3mf) | D2の椅子1個 | PLA Basic Gray | 20分28秒 / 6.68 g |
| [translucent_blue.3mf](translucent_blue.3mf) | B4のCodex本体1個 | PLA Translucent Blue | 24分07秒 / 6.53 g |
| [black.3mf](black.3mf) | ロゴ3、目6、台座3 | PLA Basic Black | 1時間00分14秒 / 22.34 g |
| [white.3mf](white.3mf) | D1本体、D2本体、D3クッション、D4アイコン、B4記号2 | PLA Basic White | 1時間32分03秒 / 30.64 g |
| [orange.3mf](orange.3mf) | D3/D4/B4のClaude | PLA Basic Orange | 1時間35分28秒 / 31.95 g |

**合計のスライサー見積り: 4時間52分20秒 / 98.14 g。** 支持等を含むスライサー値で、実時間/実使用ではない。プレート交換・支持除去・組立時間は別。開始処理の排出などで実消費は増減する。

X2D / 0.4mm / Textured PEI / 0.16mm層。白・橙は同材tree support、その他支持なし。1ジョブ1色なのでAMS全色同時装着は不要。現在入っている色/材質を割り当てる。ロゴ等の小部品はブリムから丁寧に外す。

実STL再読込、実G-codeの全23部品の初層・各部品の層連続性、ベッド内経路、設定継承、G-code保存を検査した。各 `*-layers.png` は実際の押出経路から描画したもの。

未実施: プリンターへの送信、Bambu Studio GUI再読込、現在のAMS割当・空プレート確認、実機造形、接合と支持除去の実証。別ジョブ終了後のプレート交換と材質確認を終えてから使用する。現在の印刷を停止・変更する操作は行っていない。

# 背面をコンパクトにする追加資料

利用者原文：「背面はこんな感じで割とコンパクトに収まってる方が作品的にあってる気がするからもう少し後ろ調整して」。2026-09-22の添付JPEGを無加工で保存した。

新しい写真では、背後の尖りは高さ方向の広がりを持ちながら中心付近にまとまっている。v3の後方へ長く伸びるシルエットを短縮する基準として採用。前面・中央は先の5枚で設計した形を保持した。写真だけから実寸や商品名は確定していない。

後方深さ90/60/45 mm相当を同方向のCADで比較し、45 mmを選定した。後方半径40 mm相当・36°交互配置は維持。根元12 mm相当を固定し、その後ろを縮めることで前面の形とビーズ受けを保持する。値は写真を参考に選んだ模型用寸法で、公式実測値ではない。

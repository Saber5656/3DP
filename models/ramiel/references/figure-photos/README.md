# 星型ラミエル再設計の基準写真

利用者原文：「なんか中央の部分は全然違うな／公式フィギュア見つけたからその全体像把握して再設計して」。5枚の添付原画像を変更せず保存した。商品の正式名、販売元、実寸は画像だけから確定しない。

- Photo 5：正面。5本の大きな尖り、各尖りの左右2面と中心への稜線、小さな赤球とその周囲の凹んだ折面。
- Photo 2・4：左右の側面。後方へ長く伸びる尖りがあり、薄い星の裏板ではない。前後の尖りが異なる位置へ張り出す。
- Photo 3：背面。背景側に前面の大きな尖りが見え、手前に別の5方向の尖りが集まる配置として再構成。背面だけを単独の平たい星とみなさない。
- Photo 1：斜め上・台座を外した状態。前面中央の折り込まれた面と、前後の尖りの奥行きを確認する基準。

前案の「星を縮小して3枚重ねる」構造は棄却。5本の先端・谷・内側の稜線・凹部の底を直接結ぶ面へ変更し、後方に36°ずらした別の5本を設けた。36°と背面の幅/長さは複数方向の見え方を照合した推定値であり、実測した公式形状ではない。前後が入れ違う案と同じ向きの案、背面の半径・奥行きを比較した図を実行ログに保持。

写真5の外側5頂点を手動で読み、150 mm幅の前面輪郭を二次元相似変換だけで照合した値をlandmarks.jsonに保存。遠近・レンズ補正なしで、全形状の一致を証明する値ではない。

小球は写真の比率から直径3 mmを仮値に変更。周囲の広い赤い面の見え方は市販の赤ビーズだけでは再現できない。今回は青の凹面として作り、写真と同じ赤い色分けまで寄せる場合はその凹面を後から塗る。製品の塗装工程や実際の反射機構を確認したものではない。

Webで製品名の補助調査を行ったが、同一商品を特定できなかった。一番くじの公式サイトはrobots制限で未閲覧。数学的な星型多面体の一般情報も、この個体の形の証拠としては採用しなかった。再設計の主資料はこの5枚。

# Profile title

X2D 0.4 | 0.16mm | Hollow body + stand | By object

# Profile description

実際に印刷した一体中空の本体と黒い台座の構成です。X2D・標準0.4 mmノズル・Textured PEI、0.16 mm積層、壁3周。本体は青い半透明PLA・充填0%、台座は黒PLA・充填15%。辺を下にした本体に、プレートからのみの木状サポートを付けます。

オブジェクト順で黒台座→青本体、両色ともメインノズルを使います。3MFの向き・配置を維持し、送信前に材料の割り当てを確認してください。内部サポート・接着・LED・赤いコアは不要です。他機種での実機確認はしていません。

成功時のGUIスライサー予測：3時間42分32秒、青33.64 g＋黒13.11 g＝46.75 g。実測値ではありません。

Successfully printed on an X2D with a standard 0.4 mm nozzle and Textured PEI plate. 0.16 mm layers, 3 walls; hollow body with 0% infill, stand with 15% infill. Keep the edge-down body orientation and build-plate-only tree supports. By-object order: black stand first, translucent blue body second, both on the main nozzle. No internal supports or glue. Other printer models have not been physically tested.

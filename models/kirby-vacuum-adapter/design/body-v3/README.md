# カービィ背面アダプター v3 — 外径5mm・黒PLA

**2026-09-21 現物で目的達成（利用者報告）。** ハンドクリーナー側・カービィ側とも若干の浮きがあり、テープを巻いて太く微調整した状態で成功。CAD寸法は保持し、テープの厚さ・巻き数・調整後外寸は未測定。 [現物評価の詳細](physical-result.md)

最新指示: 「ハンドクリーナー挿入部分と比較してカービィーの背中に刺す部分がでかい気がしたんだけど、カービィーの背中の穴に刺す部分って5mm になっているよね？ 穴全体が5mmだからフィラメントの外径が5mmってとこにも注意してね」

旧v2の外径28 mmは要求を誤解した設計であり撤回。実機送信前に訂正できた。既存の背面穴は拡大しない。

## 今回の形状

| 部分 | CAD寸法 | 状態 |
|---|---|---|
| 背面穴に入る細い管の外径 | 5.00 mm | 利用者指定。先端0.4 mmのみ4.4 mmへ面取り |
| 細い管の内径 | 3.00 mm | 設計値。通常区間の肉厚1 mm、面取り先端0.7 mm |
| 背面への差し込み長さ | 8 mm | 申告された穴深さに合わせた試作値 |
| 背中の外に当たる肩 | 直径14 mm | 穴には入らない。背面曲率未測定 |
| 掃除機側 | 外形36.4×12.4 mm、差し込み20 mm | 試験片30の現物評価済み断面を保持 |
| 全高 | 53 mm | CAD、STL確認済み |

細い管は滑らかな差し込み式。5 mmを超える返し・ねじ・固定リングは付けない。初期設計はカービィ自身の素材との摩擦で保持する試作。現物では両側にテープを巻いて調整後に目的を達成。抜け止め性能や気密の定量試験は未実施。外径5 mmはCADの値で、印刷後の実寸は測定が必要。クリーナーの重量をこの細い部分で支えない。

内径3 mmの通路が空気量を制限する。通れないサイズのごみは体内に残る。利用者から目的の吸引に成功したと報告された。吸引の強さや流量の定量値は未測定。

## 印刷後

1. 冷めてから外側のツリーサポートを外す。細い管をつかんでねじらず、太い本体を保持する。
2. 入口の糸・バリを除き、内径3 mmの穴が通っていることを確認する。
3. 背中の既存5 mm穴に、細い部分をまっすぐ手で差す。14 mmの肩は外側で止まる。固ければ無理に押さず、部品側のバリを確認する。背面穴は広げない。
4. 掃除機側を差し込み、部品とカービィを支えた状態で口からの吸引、背面の漏れ、外れやすさを短く試す。内側の入口が壁で塞がっていないかも確認する。
5. 緩い／漏れる場合はこの試作結果から調整する。現時点では接着・新しい穴あけを前提としない。

## 再生成

`.venv/bin/python build_body_v3.py` でCAD/STL/STEP/形状のみ3MF、`render_body_v3.py` で実STLの図を生成する。Bambu Studioで保存した `kirby-v3-5mmOD-X2D-black-PLA.3mf` は実機設定付き。再送信時はその時点のプレートとAMSを確認する。

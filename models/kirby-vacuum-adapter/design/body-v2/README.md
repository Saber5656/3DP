# 本体アダプター v2 — 黒PLAの試作

利用者指示: 「作って」「AMSに青い半透明のフィラメント追加したけどそのまま黒のPLAで実行してね」。今回印刷するのは本体と固定リングの2点。青い半透明PLAやTPUは使わない。

## 設計

- クリーナー側: 現物で評価された試験片30と同じ外形36.4×12.4 mm、差し込み20 mm、止めつば45×21×3 mm。
- 空気の通路: クリーナー側の長円から丸い内径20 mmへ滑らかに変化。カービィ本体が空気室となり、口まで管を通さない。
- カービィ側: 外側のつば直径40 mmと、内側の固定リング直径36 mm・厚さ8 mmで挟む。既存穴の通り抜け深さ8 mmに合わせ、ねじで締め具合を調整する。
- ねじ: 外径28 mm、谷径25.6 mm、ピッチ4 mm、つばからの長さ22 mm。市販M28互換ではなく、この本体とリング専用の粗いねじ。半径方向0.30 mm、軸方向0.15 mmの逃げ。8 mm壁＋0〜2 mmのシール厚を想定し、合計12 mmまでの組付け位置を幾何確認する。
- 本体の全長75 mm。PLAの固定リングを柔らかいパッキンとして扱わない。カービィの面が密着しない場合は、薄い柔らかいゴムや適切なシール材を当てて漏れを調整する。気密は現物確認が必要。

## 印刷後の取り付け

1. まずカービィを加工せず、本体とリングが手でねじ込めることを確認する。内外のねじ入口の糸やバリを除去し、無理に締め込まない。
2. 口の底を開け、固定リング（直径36 mm）が口から体内へ通せることを確認する。内側からリングを保持して締める方式なので、このアクセスが必要。
3. 本体の直径40 mmのつばを背中に当て、足や底、既存穴との位置関係を確認する。写真では既存小穴が低い位置にあるため、その中心で大径の穴を開ける指定はしない。新しい位置に開ける場合、既存の小穴も別途密閉する。
4. 新しい接続穴の完成径の目安は28.5〜29 mm。いきなり大きく開けず、実物のねじ先端が通るまで少しずつ広げる。周囲に、つばとリングで挟むための連続した素材を残す。印刷部品を当てる前には加工しない。
5. 本体を背中の外側から入れ、口から入れたリングを内側で手締めする。きつく潰すためのねじではない。顔や背中が変形しない範囲で軽く保持する。リングの向きは両端に入口面取りがあるためどちらでもよい。
6. クリーナーにつなぎ、短く運転して口から吸えるか、背面から空気が漏れないか確認する。引っ張って外れないかは手で部品を支えた状態で確認する。持ち運ぶときはクリーナー本体を持つ。

## 検査の範囲

試験片30のはめ合いは利用者評価済み。本体の形状検査、貫通、ねじの断面干渉・軸方向の引っかかりはCADから生成した形状で検査する。リングと背面の実物適合、保持力、気密、吸引は印刷後の確認。3MF/STL生成やスライスだけでこれらを合格にしない。

本体はクリーナー側の口を下にして印刷し、止めつばの下に外側サポートを付ける。リングは平置き。空気の通路やリングの内ねじをサポートで塞がない設定と層表示を確認してから送信する。

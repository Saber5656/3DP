# 524キーホルダー：フックと材料消費の改善

2026-09-28の完成品フィードバックを反映。**修正版の作成・オフライン検証済み、再印刷は未実施。**
外形は好評だったWood銅像由来の本体40 mmを保持し、頭の真上・前後左右中央・正面に垂直な輪も維持した。
同日のユーザー補足を受け、**完成品の品質を最優先に、成功した色の厚み・下地・重なりを保持する方針へ訂正**した。
口の黄色＋半透明青の混色も意図した成果。先の未印刷の31.64 g薄層案は撤回し、消費削減率を採用理由にしない。

## 実データで確認した原因

前回送信したv6のG-codeでは、最初の230層は本体が黄色のみなのに、全230層で色替え用の塔を積み、約8.73 gを使っていた。
これは色替えがなくても塔の高さを本体に合わせる積層。`flush_into_infill` や白を別ノズルにする設定だけでは除去できていなかった。
前回の色の厚みは、実物で良い発色が得られた条件。その部分を浪費と扱わず、同じ色領域・下地を保持して不要な塔を減らす。

フックは実物の積層不良の申告を受けた。写真では金具に隠れた面もあり、冷却・湿気・支持除去時の損傷など個別要因までは断定できない。
旧設計は細い丸棒の下面をサポートに載せ、横穴の円弧天井の支持を除外していた。穴が通る検査だけでこの積層上の弱点を見逃していた。

## 修正と比較

| 推定時間 | 3時間59分12秒 | 3時間26分36秒 | 3時間53分00秒 |
| 色替えのない層の塔 | 8.73 g / 230層 | 0 g / 0層 | **0 g / 0層** |

総量は8.40 g（19.6%）削減。表では `slice_info.config` の総量を用いた。材料別の丸め済みG-codeヘッダーの合計は旧v6が42.96 g、塔のみ案が35.36 gで、各0.01 gの丸め差がある。
いずれも計算上の見積りであり、秤で測った実消費ではない。前回の実測重量・残量は取得していない。

内訳も分けて確認した。経路からの推定は、本体10.64→10.69 g、支持0.31→0.29 g、塔14.79→6.30 g。
スライサー総量と経路推定の残差は17.20→17.26 g。ここには通常のXY押出として数えられない機械側の動作等が含まれるが、その全量をパージと断定していない。
厚くした輪で本体の材料は少し増え、主な節約は不要な塔の削減による。色の再現に必要な交換回数は保持した。

- 実物で成功した白1.0 mm・橙0.8 mm・青0.85 mmと黄色の下地を保持。単なる色名の一致でなく、各色の3D領域が元のv6と一致する回帰テストを追加した。修正版の実物発色は未比較。
- 短い塔を有効化し、本体をX128/Y180、塔をX30/Y10へ離した。元配置のままではスライサーの干渉検査が拒否したため、位置も修正。干渉条件は緩めていない。
- 輪の軸方向厚みを1.8→2.4 mm、外径を6.8→7.6 mmへ。下面を幅約4.10 mmの平面にし、穴の天井は45度。丸い下部と2.4 mm径・長さ4.2 mmの通過空間を保持した。
- 支持との設定隙間を0.16→0.08 mm、支持上面3層・間隔0.20 mm。外壁/内壁は40 mm/s、小周長は20 mm/s。品質を優先して速度を落とした分、塔のみ改善案より時間は増える。
- 初期のノズル準備、実際の色替え時の排出、使用材料の温度と既存の排出量設定は維持。G-codeの押出命令を削除していない。

## 今後の手順

[リポジトリ共通ルール](../../../AGENTS.md) と [品質・材料消費ルール](../../../docs/print-quality.md) に恒常化した。
`slice.py` はスライス直後に、材料予算と輪の経路の検査を実行し、失敗すると終了コードを返す。最終ファイルが変わったら再検査する。
Bambu Studioの全案件へ短い塔を無条件に適用するグローバル設定変更はしていない。案件ごとに機種・配置・干渉・外観を確認して採用する。

```sh
.venv/bin/python -m unittest discover -s models/524-keychain/statue-v7/tests -v
python3 -m unittest discover -s tools/tests -p test_print_audit.py -v
.venv/bin/python models/524-keychain/statue-v7/build.py
.venv/bin/python models/524-keychain/statue-v7/slice.py
.venv/bin/python models/524-keychain/statue-v7/slice.py --mode coupon
```

幾何・座標の7テスト、監査21テストを実行。色領域保存のテストは旧薄層案で失敗し、成功した色構成へ戻して通過した。元のv6は無交換層タワー0.1 g予算で要検討、改善本体・試験片は合格。予算は品質上必要な消費の絶対上限ではない。原本v6は保持。
CLIの `T65279`/`T65535` は機械のパーク用命令で、[前回の公式マクロ照合](../statue-v6/print-run-20260927/macro-source-check.json)を再利用。色替え回数に含めていない。
残ったスライス警告は短い塔で従来型タイムラプスが使えない旨。今後送信する際はタイムラプスOFFと、現物の装着・ベッド状態を確認する。

未実施：修正版のGUIでの最終保存/送信確認、実物の輪の品質・金具適合・強度、色構成を保持した修正版の発色。現在の候補を実機確認済みと扱わない。

履歴：commit `cb2ea58` の31.64 g・32交換案は、白0.64/橙0.4/青0.64 mmに薄くした未印刷の比較案。ユーザーの品質優先の意図に沿わないため現行候補から撤回した。この削減率を現在の成果として引用しない。

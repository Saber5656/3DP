# ダウンロード内の3Dデータの保管先

2026-10-01にDownloads内のモデル・スライスデータ37ファイルを確認した。同じSHA-256の27ファイルは既存の3DP内保存先を正本とし、未保管の10ファイルを [files](files/) に原本と同じバイト列で取り込んだ。
全37ファイルの保存先とSHA-256は [manifest.json](manifest.json)。Downloadsのコピーは残しているが、今後の保管・更新は3DP内で行う。

この取込フォルダーは履歴・未整理原本の保管先であり、印刷待ち一覧ではない。外部から取得したモデル、過去の試作、準備候補も含む。取り込んだファイルの新規スライス・実機検証は行っていない。実際に送るファイルは各プロジェクトの最新README・印刷記録で判断する。
新しいモデルは該当プロジェクトの `output/` 等、スライス済みデータは `slicing/`・`printing/`・`print-run-*` 等のプロジェクト内フォルダーへ保存する。
